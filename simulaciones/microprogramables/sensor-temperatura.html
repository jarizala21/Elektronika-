El Arduino (o ESP32) lee el sensor y publica cada valor en un tema MQTT. La Raspberry Pi hace de servidor (broker Mosquitto), guarda los datos (InfluxDB) y los dibuja (Grafana). Si un valor sale de los límites, manda el aviso por correo y Telegram.

Arduinoak (edo ESP32-k) sentsorea irakurtzen du eta balio bakoitza MQTT gai batean argitaratzen du. Raspberry Pi-k zerbitzari lana egiten du (Mosquitto broker-a), datuak gordetzen ditu (InfluxDB) eta marrazten ditu (Grafana). Balio bat mugetatik ateratzen bada, abisua posta eta Telegram bidez bidaltzen du.

#include <DHT.h>
#include <PubSubClient.h>   // MQTT

DHT dht(4, DHT22);

void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) return;   // lectura fallida

  mqtt.publish("zerbitzaria/tenperatura", String(t).c_str());
  mqtt.publish("zerbitzaria/hezetasuna",  String(h).c_str());

  if (t < 10 || t > 50) {
    mqtt.publish("zerbitzaria/alarma", "1");  // la Raspberry envía correo y Telegram
  }
  delay(5000);   // una lectura cada 5 s
}

DHT11 / DHT22

Sensor digital de temperatura y humedad con un solo cable de datos. El DHT22 es más preciso (±0,5 °C) y mide de −40 a 80 °C.

Tenperatura eta hezetasuneko sentsore digitala, datu-kable bakarrekoa. DHT22 zehatzagoa da (±0,5 °C) eta −40tik 80 °C-ra neurtzen du.

MQTT

Protocolo ligero de publicar / suscribirse: los dispositivos publican en «temas» y quien esté suscrito recibe los mensajes. El broker los reparte.

Argitaratu / harpidetu protokolo arina: gailuek «gaietan» argitaratzen dute eta harpidetuta dagoenak mezuak jasotzen ditu. Broker-ak banatzen ditu.
