Trozo del disco que el sistema trata como si fuera un disco independiente (C:, D:…). Sirve para separar sistema y datos o tener dos sistemas operativos.

Sistemak disko independente bat balitz bezala tratatzen duen disko-zatia (C:, D:…). Sistema eta datuak bereizteko edo bi sistema eragile izateko balio du.

Crear el sistema de archivos dentro de una partición. Rápido: solo vacía el índice (los datos se podrían recuperar). Completo: además revisa sectores y sobrescribe.

Partizio baten barruan fitxategi-sistema sortzea. Azkarra: aurkibidea bakarrik husten du (datuak berreskura litezke). Osoa: gainera sektoreak berrikusi eta gainidazten ditu.
